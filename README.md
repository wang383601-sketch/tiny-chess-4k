An original 4 KB Python chess engine: a 10x12 mailbox board, iterative deepening alpha-beta with a transposition table, killer and history ordering, null-move pruning, late-move reductions and a captures-only quiescence search, searching a fixed node budget so every move is deterministic.

## Run it

```sh
python3 -P -s main.py
```
